# Changelog

### Desktop App
 - New app icon: a sound wave with two fading echoes, drawn to the macOS icon grid so macOS 26 no longer puts it on a grey tile. On macOS the Dock icon follows the active theme's colors while echo is running
 - The playing song in the playback bar and an artist's Popular tracks can be dragged into a sidebar playlist; dragged tracks show their cover, title and artist instead of just the name
 - Artist pages load one page of the active discography chip and offer a Load more row instead of walking every release up front; each chip is fetched on first use and remembered for the session, and compilations now sit under Appears On
 - What's New only fetches each followed artist's own albums and singles and paces the walk, so a launch no longer burns through the artist-albums quota for hours; various-artists compilations no longer show up in the feed
